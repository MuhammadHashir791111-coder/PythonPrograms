## 🚀 Getting Started

### Prerequisites

- Python installed on your system.
- Git installed on your system.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/MuhammadHashir791111-coder/PythonPrograms.git
   ```

2. Navigate to the project directory:

   ```bash
   cd PythonPrograms
   ```

3. Run a Python program:

   ```bash
   python PrimeNO.py
   ```

   On Windows, you can also use:

   ```bash
   py PrimeNO.py
   ```

Replace `PrimeNO.py` with the name of the Python file you want to execute.
